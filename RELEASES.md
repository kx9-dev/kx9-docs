# Releases and package verification

Release tags identify real source commits. Each release has source archives,
an npm-compatible tarball where applicable, and SHA256SUMS.txt.
Verify a downloaded file with sha256sum and compare with the release checksum.

The downloadable tarballs are release distributions, not a promise of npmjs
registry publication. The package name, repository, version and license are
declared in package.json. Use the source README for build prerequisites.

Version 0.1.0 is an initial source prerelease. It is not a mainnet audit or
approval to fund or enable an executor. Changelogs describe implemented code,
not fabricated adoption, profit, usage or contributor counts.
